# **Documentation & Annotation Tools**

Proper documentation of research data and experimental procedures is essential for reproducibility, collaboration, and compliance with funder requirements. TUM provides several tools to help researchers document their work systematically.

## **TUM-Provided Tools**

### **eLabFTW (Electronic Lab Notebook)**

[eLabFTW](https://www.ub.tum.de/en/eln) is the official **Electronic Lab Notebook (ELN)** for TUM researchers. It replaces paper-based lab notebooks with a digital system that automatically captures timestamps, links datasets to experiments, and enables structured documentation of protocols.

**Key features:**
- Timestamped entries for audit trails
- Linking experiments to datasets and protocols
- Team collaboration with access controls
- Export for archiving and compliance

### **TUM DataTagger**

[TUM DataTagger](https://www.ub.tum.de/en/datatagger) is a web-based tool for **structuring, versioning, and annotating research data** collaboratively. It helps teams add descriptive metadata to datasets before sharing or archiving, with transparent rights management.

**Key features:**
- Collaborative annotation of datasets
- Version control for data changes
- Flexible access and editing rights
- DFG-compliant documentation

## **Choosing a Documentation Tool**

| Use Case | Recommended Tool |
|----------|------------------|
| Daily experimental documentation | eLabFTW |
| Collaborative data annotation | TUM DataTagger |
| Code and analysis documentation | Git + README files |
| Simple project documentation | README.txt in project folder |

## **Other ELN Options**

If eLabFTW doesn't fit your specific workflow, explore alternatives using the [ELN Finder](https://eln-finder.ulb.tu-darmstadt.de/) from TU Darmstadt and ZB MED. This tool helps you compare electronic lab notebooks based on features, disciplines, and requirements.
